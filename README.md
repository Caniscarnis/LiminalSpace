# Project Title
LiminalSpace

## Project Option
Website

## Project Description
This site is made to inform users on the history and lore of liminal spaces. It also discusses their popularity within our current culture as well as provides image examples of liminal spaces.

## Theme Interpretation
This project is based on the concept of liminal spaces. 

## Intended User or Player
This project is designed for users of any age who are interested in liminal horror. 

## User or Player Goal
What should the user or player accomplish?

## Main Features
The main page is used as both the main navigation point. It also describes to the user what liminal space is. The history page explains the history of some of the most influential examples of liminal space. The other page featured links to a gallery of examples/photography of liminal spaces

## JavaScript Features
Javascript allows for the user to click on text headers to open up to the main text paragraphs. 

## Responsive Design
The text enlarges on smaller screens and the text images crunches down to adapt to said smaller screens. 

## User Testing
During the original draft users reported readability issues with both the text color and the text size, both were updated in the final draft.
